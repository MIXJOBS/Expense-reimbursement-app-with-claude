# Sprint 2 受け入れ条件（PO作成）

出典：経費精算アプリ プロダクトバックログ（PO管理のDoc）。内容を変えたいときはPOに相談すること。

## 最初にやること：ログインAPIのレート制限

- [ ] 同じIPからPOST /auth/loginを1分間に11回以上呼ぶと、429になる
- [ ] レート制限の応答も { code, message } の形で返す

## PBI 3：経費申請の登録・編集

- [ ] 申請者は下書きを作成・編集・削除できる。項目は利用日・金額・科目・内容
- [ ] 金額は1円〜1,000,000円の整数。小数・0以下・上限超えは400
- [ ] 科目は「交通費・交際費・消耗品費・その他」から選ぶ。内容は200文字まで
- [ ] ステータスや申請者IDをリクエストで送ると400（サーバーが決める値）
- [ ] 一覧には自分の申請だけが出る。1ページ20件のページネーション付き
- [ ] 他人の申請をID指定で取得・編集・削除・提出しようとすると404
- [ ] 提出すると「下書き」から「申請中」になる。上長が未設定のユーザーは提出できず409
- [ ] 申請中・承認済み・経理確認済みの申請は、編集・削除すると409

## PBI 4：承認・差し戻し

- [ ] 承認者は、直属の部下の「申請中」の申請だけを一覧・閲覧できる。それ以外は404
- [ ] 承認すると「承認済み」、差し戻すと「差し戻し」になる。差し戻しには理由（500文字まで）が必須
- [ ] 申請者本人は、ロールに関係なく自分の申請を承認・差し戻しできない
- [ ] 「申請中」以外の申請を承認・差し戻しすると409
- [ ] 承認と差し戻しが同時に来ても、成功するのは片方だけ（もう片方は409）
- [ ] 差し戻された申請は、申請者が編集して再提出できる
